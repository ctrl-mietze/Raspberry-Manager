# Raspberry Manager v10.3.0 — Android + Windows

**Build · Flash · Connect · Manage** 💜

This is the first combined public Raspberry Manager distribution with a shared Android/Windows repository, a desktop installer, genuine Windows screenshots and a matching bilingual project website.

> **Experimental community build.** Hardware flashing, all Raspberry Pi Connect account flows and exact cross-platform functional parity are not certified. Keep backups and use explicit device/erase confirmation.

## Download assets

| Platform | File | Size |
| :-- | :-- | --: |
| **Android** | `RaspberryManager-Android-v10.3.0.apk` | 61,687,142 bytes |
| **Windows x64** | `RaspberryManager-Windows-v10.3.0-Setup.exe` | 147,351,006 bytes |
| **Integrity** | `SHA256SUMS.txt` | Release checksum manifest |

The Android APK preserves the package name `dev.mietze.raspberrymanager`, versionCode `100300`, and the signing certificate used for the earlier v10.2.0 debug APK.

The Windows NSIS installer is a user-level installable application (Windows 10/11 x64). It is **not Authenticode-signed**; SmartScreen may warn. The installer bundles an optional copy of the **official Raspberry Pi Imager 2.0.12 installer** with a separate opt-in launch. The original Imager is not installed silently.

## Android update highlights

- Removed the initial “What would you like to do?” chooser.
- The main-header USB icon remains available for opening the native Raspberry Pi Imager.
- Image Designer introduces **Ready · Continue** with explicit choices for **EmulateLoad** (dry-run diagnostic) and **Flash on Device** (actual Imager handoff).
- Pi Magic Workbench responsive improvements for portrait and landscape, more orderly toolbars and panels.
- Added focus/search, linked selection, right/bottom alignment, distribution and reporting tools.
- Raspberry Pi Connect native device list supports search, online/offline filters and responsive cards.
- Existing SSH and imaging mechanisms remain separate from Workbench simulation.

**Validation recorded during the Android v10.3.0 build:**
Gradle `assembleDebug` successful; **279 JVM tests (278 passed, 1 skipped, 0 failed)**; **33 Connect DOM adapter tests** and **18 clipboard tests** passed. The final APK archive and certificate were verified.

## Windows 10.3.0

- New native Windows app shell with matching Raspberry Berry theme and custom installer icon.
- Real desktop React UI captured for Home, Image Designer and Workbench.
- Stack builder with card capacities, linked blocks, validations and Ready workflow.
- Visual Workbench with **68 block types**, templates, editable inspector, snapping, zoom/pan, connections, grouping, arrangement, search, JSON/SVG export and EmulateLoad scenario reports.
- Local SSH profile manager, **ssh2** connection transport, host-key fingerprint approval and **xterm.js** terminal.
- Dedicated embedded official Raspberry Pi Connect browser profile with native device listings where supported and official WebRTC session rendering.
- Read-only Windows disk inventory; separate launch of official Raspberry Pi Imager for actual media writing.
- Source project, tests, website and design artwork included in this repository.

**Validation recorded for Windows:** Vite/TypeScript build, 14 logic/contract tests, NSIS packaging and captured Home/Builder/Workbench screens. A successful build is not proof of every live SSH, Connect or disk-write scenario.

## Known limitations

- Workbench *designs* are not physical boot images.
- EmulateLoad is a dependency dry-run, not firmware, CPU or OS emulation.
- Android/Windows share core workflows and schema, but the advanced Android-only exports and native disk operations are not all mirrored exactly in Windows.
- Official Pi Connect login/session success depends on current provider behavior and has not been live-tested for every account or Raspberry hardware configuration.
- Windows installer is currently unsigned.
- No actual USB/SD erasures were performed during automated validation.
